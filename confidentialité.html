1. Données collectées

Sana-e collecte des données telles que : email, données saisies (humeur, stress, sommeil), données d’usage et informations techniques.

2. Finalité

Ces données permettent le fonctionnement de l’application, l’analyse des données et l’amélioration du service.

3. Base légale

Le traitement repose sur le consentement explicite de l’utilisateur.

4. Hébergement

Les données sont hébergées via des services cloud sécurisés, potentiellement situés dans l’Union européenne.

5. Durée de conservation

Les données sont conservées pendant l’utilisation du service.

6. Droits

Vous pouvez demander l’accès, la modification ou la suppression de vos données à tout moment.
